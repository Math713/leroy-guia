# Leroy Guia 🏠

Projeto acadêmico desenvolvido com o objetivo de criar um assistente virtual inteligente para auxiliar clientes em problemas domésticos, reformas e manutenção.

O Leroy Guia utiliza inteligência artificial para fornecer orientações e recomendar produtos relacionados às necessidades dos usuários.

## 🚀 Tecnologias

**Frontend**
- React
- Vite
- JavaScript
- Bootstrap

**Backend**
- Python
- FastAPI
- Google Gemini API

## 💡 Objetivo

Desenvolver um MVP que demonstre como a inteligência artificial pode melhorar a experiência de compra e auxiliar clientes na identificação de soluções para problemas domésticos.

## 👨‍💻 Projeto acadêmico

Desenvolvido para fins educacionais e demonstração de funcionalidades.
